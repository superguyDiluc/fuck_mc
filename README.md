# 项目介绍
一款基于《鸣潮》游戏而设计的声骸自动化处理工具

可以筛选出自己想要的有用词条

# 克隆项目
```
git clone https://github.com/superguyDiluc/fuck_mc.git
```

# pip安装依赖库
在项目根目录执行
```
pip install .
```

# 前提
- 开启窗口模式
- 分辨率设置为`1600 x 900`
- 在命令行环境中需要授予管理员权限

# 使用方法
- 将界面调整到背包声骸界面，建议使用时间排序
- 在scripts文件夹中的config.py中可以更改你需要筛选的相应的套装、COST、属性等等，自定义配置
- 执行`python main.py`即可运行
- 按`Q`可以退出程序
